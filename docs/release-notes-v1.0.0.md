# VoiceForge 1.0.0

The first stable public release of the local Venice-powered voice studio.

## Highlights
- Clone permitted voices from uploads or YouTube and save named handles locally.
- Generate MP3 speech and narrated MP4 videos.
- Optional user-installed lip-sync; Wav2Lip and weights are not redistributed.
- Real render stages, cancellation, GPU capability detection, and Fast/HQ modes.
- API keys stay in the operating-system credential vault.

## Requirements
Python 3.10–3.12, ffmpeg/ffprobe, and a funded Venice API key. See the README for installation and responsible-use requirements.
